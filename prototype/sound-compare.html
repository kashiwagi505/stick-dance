音の聞き比べ

同じ4小節（ドラム・ベース・旋律・和音・高い旋律）を、4種類の音で鳴らします。ゲームの分身5人が重なった状態に近い形です。
下のチェックで楽器を外すと、1つずつの音色や、重ねたときの濁り方を聞き比べられます。2周くり返して止まります。

鳴らす楽器:

A. 今の試作の音

Web Audio を直接・合成音
  • 試作と同じ作り（三角波・のこぎり波・ノイズのドラム・軽いエコー）
  • 軽い。ゲーム機っぽい電子音

B. 合成音を磨いたもの

Web Audio を直接・合成音（ライブラリなし）
  • 響き（リバーブ）・音量の整え（コンプレッサー）を足した
  • 旋律はつま弾く音、高い旋律はベル、和音はふわっと広がる音
  • ライブラリなしでどこまで行けるかの見本

C. Tone.js の音色

Tone.js・合成音
  • Tone.js の部品（厚いのこぎり波・FMのベル・AMの和音・太鼓用の音源）
  • コーラス・リバーブも Tone.js

D. 録音した楽器の音

Tone.js の Sampler・ピアノとドラムの録音
  • 旋律・和音・高い旋律はグランドピアノの録音、ドラムは生ドラムの録音、ベースは C と同じ合成音
  • 聞き比べ専用（Tone.js が公開している見本の音を読み込む）。製品に使うなら素材の権利の確認が要る
