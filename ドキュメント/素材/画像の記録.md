# 画像の記録

公開する画像の出所の記録（→ 非機能要件 N7、受け入れ条件 AC5）。**1画像1行。** 画像を足す・作り直すたびに書く。

## 規約の確認

- 生成に使った道具: Codex（OpenAI）の画像生成（`image_gen`）。
- 確かめた規約: OpenAI 利用規約（https://openai.com/policies/row-terms-of-use/ 。日本語版 2026年1月1日発効の版）。
- 確かめた結果:
  - 「コンテンツの所有権限」に、お客様はアウトプットを所有し、OpenAI はアウトプットに関する権利をお客様に譲渡するとある。公開・商用利用を禁じる条項は無い。
  - 禁止事項に「人が作り出したものではない場合に、アウトプットを人が作り出したものと表示すること」がある。そのため、ゲーム内のクレジット（[DLG01_クレジットの窓](../02_基本設計/画面設計/DLG01_クレジットの窓.md)）に、背景の絵を OpenAI の画像生成で作ったことを出す。
  - 「コンテンツの類似性」にあるとおり、ほかの利用者が似た絵を受け取ることがある。似た絵に対する独占は主張しない。
- 規約を確かめた日: 2026-11-16（下の表の「規約を確認した日」も同じ）。
