# 03 インフラ要件

棒人間ダンシングを開発・配信する環境を定める。

## 1. 動作環境と配信

| ID | 要件 |
|---|---|
| I1 | **GitHub Pages で静的ファイルとして配信する**（→ [判断ログ](判断ログ.md) D14）。サーバー側の処理は持たない。共有URL（F8）もサーバーなしで再生できる形にする |
| I2 | ブラウザは**PCの Chrome 最新版**を基準とする（→ [非機能要件](02_非機能要件.md) N1） |
| I3 | 開発は開発者のPC（会社PC・自宅Mac）で行う。Node.js 22 以上を想定。ビルド・起動のコマンドは技術選定と合わせて決める |
| I4 | **実行時・配信時に読むファイルは、作り直せるものでもリポジトリに含める。** 生成物を `.gitignore` に入れて GitHub Pages で 404 になった前例がある（「アプリ制作の情報をvaultにどこまで入れるか」（secondbrain vault の知識ページ）） |

## 2. 環境変数

なし（サーバー・外部APIを使わないため）。必要になったら `.env.example` を置き、`.env` はGitへコミットしない。

## 3. 外部サービス

| サービス | 用途 | 備考 |
|---|---|---|
| GitHub | リポジトリ・GitHub Pages での公開 | 無料プランでは非公開リポジトリから Pages を出せない。公開の時点でリポジトリを公開にする（→ D14） |
| Codex（自宅Mac） | 背景・トップページの絵の生成 | 実行時には使わない。規約の確認は N7 |
