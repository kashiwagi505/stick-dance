# 01 機能要件

棒人間ダンシングの機能を定める。決定の理由は [判断ログ](判断ログ.md)、完成の判定は [納品・検収要件](05_納品・検収要件.md)。

| ID | 要件 |
|---|---|
| F1 踊り | キーを押している間、決まった体の部分を決まった向きに引く（画面の左側の手＝WASD、画面の右側の手＝矢印キー。引く向きも画面の上下左右で、A・← は画面の左へ引く）。体全体がつられて動き、離すと立ち姿へ揺れ戻る。引く強さは試作の「強」を基準にする（→ D2） |
| F2 その場の音 | 頭が動いた8分音符の拍だけ、頭の高さに対応した音を鳴らす。音の高さは音階に丸める。止まっていると鳴らない（→ D4）。頭の左右の位置で、音の聞こえる左右（パン）を変える。左にいれば左から、右にいれば右から聞こえる（→ D25） |
| F3 ループ | 4小節のループを回し、ドラムと伴奏を流し続ける（→ D5） |
| F4 分身 | 1周で一定以上鳴らすと、その周の踊りと音が分身として残り、次の周から隣で同じ踊りを繰り返す。踊っている間は分身の音を鳴らさず、全員の音は鑑賞で初めてまとめて鳴らす。最後の1人を消せる。最大5人（→ D6・D26） |
| F5 楽器 | 人ごとに楽器を1つ持つ。踊っている最中からその楽器の音で鳴る（→ D7）。踊る前に選べ、選ばなければまだ使っていない楽器を順番に付ける（→ D8）。棒人間の色は楽器の色。楽器の音は録音した楽器の音（サンプル）と合成の音を使う（→ D18・D22）。楽器の割り当ては [音の設計方針](../02_基本設計/設計方針/音の設計方針.md) |
| F6 結びつきの表示 | 鳴った瞬間に、頭・音階・分身が光るなどして、どの動きがどの音かが目で分かる（→ D1） |
| F7 鑑賞 | 分身を舞台に並べ、1周ごとに1人ずつ加え、全員そろってから終わる（→ D6） |
| F8 共有 | 鑑賞の中身をURLにする。そのURLを開くと、遊ばずに同じ鑑賞が再生される（→ D13） |
| F9 導入 | 初めての人が、最初の1周のうちに「キーで引くと鳴る」ことに気づける |
| F10 クレジット | 使った素材の作者とライセンスを、ゲームの中（トップページから行ける場所）に表示する（→ N7） |
