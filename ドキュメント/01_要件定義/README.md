# 棒人間ダンシング 要件定義（入口）

> キーで棒人間を引っ張って踊らせると、その踊りが4小節のループに音として重なり、最大5人の分身が並ぶ。最後に全員の踊りと曲を「鑑賞」し、それをURLで他の人に共有できる。一般公開する。
> 踊るとその場で鳴るので、どの動きがどの音かが分かったまま曲ができていく。

> 出所: secondbrain vault `30_Projects/棒人間ダンスで曲ができるゲーム/` で 2026-11-11〜15 に固めた要件定義を、ハーネスの構成に合わせて分割したもの。**以後はこのフォルダが正本。**
> 体験の芯・操作・音の仕組みは、試作（`prototype/index.html`）で手応えを確かめてから決めた。

## 1. 目的

- 音楽を作った経験がない人でも、体を動かす感覚で曲ができ、それを自分の踊りとして見て楽しめること
- 前作（配達で曲ができるゲーム。2026-11-11 に閉じた）で分かった「行動と音がその場で結びつかないと、自分の作品と感じられない」を、最初から満たす形で作ること

## 3. 範囲

### 最初の版でやる

- 試作で決まった遊び（引っ張る操作・ループ・分身・楽器・鑑賞）を、初めての人にも分かる形に整える
- 遊び方が分かる導入（最初の1周で操作が分かる程度）
- 鑑賞の共有（URL）
- 一般公開（GitHub Pages）

### 最初の版でやらない（2026-11-15 確認済み）

- スマホ・タブレット（タッチ操作）
- お題・点数・ランキング
- 動画や音声ファイルの書き出し
- 3D表示
- アカウント・サーバーへの保存（共有はURLだけで完結させる）
