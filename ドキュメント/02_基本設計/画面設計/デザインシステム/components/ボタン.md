# ボタン

[デザインシステム](../readme.md) の共通部品。実数は [部品.css](部品.css)（`.button`）と [tokens.css](../tokens/tokens.css)。

## 1. 種類

| 種類 | 見た目 | 使うところ |
|---|---|---|
| 主ボタン（`.button--primary`） | 照明の白（`--color-light`）の地に、夜の藍（`--color-stage`）の文字。両端が丸い | 画面で最も主な操作1つだけ（例: SCR01「はじめる」）。1画面に2つ置かない |
| 副ボタン（`.button--secondary`） | 透明の地に照明の白の文字、1px のもやの枠 | 主ではない操作（例: SCR01「クレジット」） |

ボタンに楽器の色を使わない（→ [readme.md](../readme.md) 1.2）。

## 2. 寸法

| 項目 | 主ボタン | 副ボタン |
|---|---|---|
| 高さ | 56px | 48px |
| 左右の余白 | 48px | 24px |
| 文字 | `--text-lead` 20px・太字 | `--text-small` 16px |
| 最小の幅 | 200px | 48px |

## 3. 状態

| 状態 | 主ボタン | 副ボタン |
|---|---|---|
| 通常 | 白の地 | もやの枠 |
| マウスを乗せた | `--glow-light` で光る | 枠が照明の白になる |
| フォーカス（キーボード） | 通常の見た目＋`--focus-ring`（4px 離す）＋`--glow-light` | 通常の見た目＋`--focus-ring` |
| 押している | 1px 下がる | 1px 下がる |
| 押せない（`disabled`） | 透明の地、**2px のもやの破線の枠**、もやの文字。光らない。カーソルは `not-allowed` | もやの文字、破線の枠 |

- 押せない状態は色だけでなく、**破線の枠**と**文言**（例: 「準備中」）で伝える。押せない理由は、すぐ近くに [状態の案内](状態の案内.md) で出す。
- 押せない間も `disabled` 属性を付け、読み上げで「使用不可」と伝わるようにする。

## 4. 文言

- 押すと何が起きるかを動詞で書く（「はじめる」「再読み込みする」）。「OK」「送信」は使わない。
- 同じ操作は全画面で同じ文言にする。文言の正本は各画面設計と `src/view/` の文言定義（→ [アプリケーション実装方針](../../../../基準書/アプリケーション実装方針.md) 4章）。
