# 譜面の帯

[デザインシステム](../readme.md) の共通部品。踊りがそのまま譜面になっていることを見せる、舞台の下の光の帯。実数は [部品.css](部品.css)（`.score`）。

## 1. 形

- **人ごとに1段、1段は1周の8分音符の数（4小節なら32）のマス。** 小節の区切り（8マスごと）は間を広げる。
- 段は上から 1人目・2人目…の順。SCR02 では、いま踊っている人の段を一番下に置く。
- マスは、鳴らない拍は `--color-floor` の小さな四角。**音が鳴る（鳴った）拍のマスは、その人の楽器の色で点く。**
- 再生の位置（いまの拍）は、全段を縦に貫く照明の白の細い柱で示し、拍ごとに右へ進む。周の頭で左端に戻る。
- その拍で音が鳴った瞬間、そのマスは `--glow-soft` で一瞬（拍の半分）光る。

## 2. ふるまい

- 分身の段は、その人の1周ぶんの音がはじめから点いている（決まった譜面）。踊る画面（SCR02）では分身の音を鳴らさないので、分身の段は拍ごとに光らせず、光るのは今踊っている人の段だけ。鑑賞では、加わった全員の段が鳴った拍で光る（判断ログ D26）。
- いま踊っている人の段は、鳴った瞬間にそのマスが点き、その周のあいだ点いたまま残る。周が変わると空に戻る。
- 鑑賞では、まだ加わっていない人の段は点かない（マスだけが見える）。加わった周から点く。
- **帯は読み上げない飾り（`aria-hidden`）にする。** 段を色だけで区別するため。誰がどの楽器かは帯の外の文字で出す（→ [readme.md](../readme.md) 1.2。文言は各画面設計）。
- 再生位置の柱と鳴った瞬間の光は遊びの中身（拍と音）なので、`prefers-reduced-motion` でも止めない（→ readme.md 1.7）。

## 3. 寸法

| 項目 | 値 |
|---|---|
| マス | 幅 20px・高さ 8px、角 2px |
| マスの間 | 横 4px（小節の区切りは 24px）、段の間 4px |
| 帯の幅 | 32マスで 812px（舞台の幅 960px に収める） |
| 帯の高さ | 段の数 × 12px − 4px（5段で 56px） |
