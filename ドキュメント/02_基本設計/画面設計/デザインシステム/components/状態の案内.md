# 状態の案内

[デザインシステム](../readme.md) の共通部品。待っている・失敗したなど、画面の状態を1〜2行で伝える。実数は [部品.css](部品.css)（`.status`）。

## 1. 種類

| 種類 | 見た目 | 使うところ |
|---|---|---|
| 待ち（`.status--wait`） | もやの文字（`--color-haze`）。先頭に、拍（`--beat`）の2倍の周期でゆっくり明滅する小さな丸 | 楽器の音を読み込んでいる間など |
| 知らせ（`.status--info`） | 照明の白の文字。印は付けない | 操作がうまくいったこと（SCR03 の「共有URLをコピーしました」など） |
| 失敗（`.status--error`） | 照明の白の文字を `--color-stage-raised` の面に置き、**2px の照明の白の破線の枠**で囲む。先頭に「！」の印 | 楽器の音を読み込めなかったときなど |

- 失敗に赤を使わない（→ [readme.md](../readme.md) 1.2）。失敗は、**枠の破線・「！」の印・文言**の3つで伝える。
- 待ちの丸の明滅は飾りの動きなので、`prefers-reduced-motion: reduce` のときは止めて点いたままにする。

## 2. 置き方と読み上げ

- 状態の原因になっているボタンのすぐ下に置く（例: SCR01 では「はじめる」の下）。
- 案内の領域は常に置いておき、中身だけを入れ替える。`role="status"`（`aria-live="polite"`）を付け、入れ替わったときに読み上げられるようにする。失敗は `role="alert"` にする。
- 文字は `--text-body` 18px。2行までにする。

## 3. 文言

- 何が起きているか、何をすればよいかを書く。謝らない。「エラーが発生しました」のようにぼかさない。
- 例: 「楽器の音を読み込んでいます」「楽器の音を読み込めませんでした。ページを再読み込みしてください。」
- 文言の正本は各画面設計と `src/view/` の文言定義。
