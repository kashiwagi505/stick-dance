# モックアップ

画面設計書（`../画面設計/SCRXX_○○画面.md`）と同名の HTML を置く。1画面につき設計書1ファイルとモックアップ1ファイルで、片方だけ変更しない（→ [ドキュメント/AGENTS.md](../../AGENTS.md)「画面設計とモックアップ」）。

## 置き方

| 置くもの | 場所 |
|---|---|
| 画面の HTML | このフォルダの直下（`SCR01_トップ画面.html` など） |
| 画面固有の CSS | `css/`（画面と同名） |
| 画面固有の JavaScript | `js/`（画面と同名） |
| 画像 | `img/` |
| 2画面以上のモックアップで共通に使う CSS・JavaScript | `css/`・`js/` に、画面名ではなく中身の名前で置く（`css/舞台.css`、`js/舞台の描画.js`、`js/鑑賞の描画.js`。SCR02〜SCR04 で使う、舞台の枠と仮の棒人間・譜面の帯の描画） |

- **共通の見た目はデザインシステムのファイルを相対パスで直接読む。** `../画面設計/デザインシステム/tokens/tokens.css`（トークンとタイトル書体）と `../画面設計/デザインシステム/components/部品.css`（地・フォーカス・ボタン・状態の案内）。モックアップ側へ写さない。
- ビルド不要で、HTML をそのまま開いて確認できる状態にする。
- 状態を見比べるための操作（「モックアップの状態」など）は、画面の外の左下に置き、`mock-` で始まる名前を付けて、実装しないものだと分かるようにする。

## 開き方

`file://` で直接開くと、アプリ内ブラウザでは相対パスの CSS・JavaScript・書体が読み込まれない。リポジトリのルートを配信して開く。

```bash
python3 -m http.server 8123 --bind 127.0.0.1
```

`http://127.0.0.1:8123/ドキュメント/02_基本設計/モックアップ/SCR01_トップ画面.html` を開く。Claude Code のアプリ内ブラウザでは、このコマンドを Bash で起動してから、その URL を `preview_start` の `url` で開く（`.claude/launch.json` は Git 管理外。Mac では launch.json から起動した python が「書類」フォルダを読めずに失敗することがある）。

## 利用してよい外部リソース一覧

**なし。** 外部 CDN・外部の Web フォントは使わない。書体はデザインシステムの `fonts/` に同梱したものだけを使う（→ [素材/書体の記録](../../素材/書体の記録.md)）。実装（`src/`）でも外部 CDN を参照しないため（→ [アプリケーション実装方針](../../基準書/アプリケーション実装方針.md) 9章）、モックアップでも同じ条件で見た目を確かめる。
