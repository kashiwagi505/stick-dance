# 技術選定の設計方針

棒人間ダンシングで使う技術と、その理由・決まりを定める。決定の経緯は [判断ログ](../../01_要件定義/判断ログ.md) D18〜D20。

## 1. 使う技術

| 部分 | 使うもの | 理由 |
|---|---|---|
| 言語・ビルド | TypeScript（strict）・Vite | 前作のハーネスがそのまま使える |
| テスト・静的解析 | Vitest（単体）・Playwright（E2E）・ESLint | 同上 |
| 棒人間・舞台の描画 | **Canvas 2D を直接使う**（ライブラリなし） | 描くのは線・円・背景の絵だけ。試作で足りている（D19） |
| トップページ・ボタン・案内 | **HTML と CSS** | 生成した絵を背景に置きやすい。文字とボタンを作りやすい |
| 音 | **Tone.js**（Sampler・Players・エフェクト）。**Transport は使わない** | 録音した楽器の音を使う（D18）。音の高さごとの割り当てと読み込みを任せる。拍は自分で刻む（3.2） |
| 楽器の音 | **録音した楽器の音（サンプル）と、Tone.js で合成する音を混ぜる。** 録音はリポジトリに入れて配信する | 聞き比べで本人が選んだ（D18・D22）。録音の素材は 4章の条件を満たすものだけ。割り当ては [音の設計方針](音の設計方針.md) |
| 体の動き（物理） | **自作**（試作の Verlet 法を引き継ぐ） | 小さく、同じ入力から必ず同じ動きにできる（3.1） |
| 共有URL | ブラウザ標準の圧縮（`CompressionStream`）＋ URL の `#` に入れる | サーバーが要らない（I1） |
| 公開 | GitHub Actions で GitHub Pages へ | ハーネスに `pages.yml` がある |

使わないと決めたもの: Phaser（画面の切り替えは HTML の表示切り替えで足りる。前作で版の違いに手間取った）、物理ライブラリ（同じ入力から同じ動きになることを自分で保証できない）。

## 2. コードの分け方（層）

```text
src/
├── core/    踊り（物理）・ループ・分身・記録。純粋な TypeScript。描画・音・DOM・時計に触れない
├── music/   記録 → 鳴らす音の並び（どの拍に、どの楽器の、どの高さ）。純粋な TypeScript
├── share/   記録 ⇔ URL（圧縮・展開）
├── audio/   Tone.js で鳴らす。楽器の読み込み・拍の予約・エフェクト
├── view/    Canvas の描画と HTML の画面（トップ・踊る・鑑賞・共有を開いた画面）。キー入力を受ける
└── main.ts  つなぐ
```

- `core`・`music`・`share` は Tone.js・Canvas・DOM・`Date.now()`・`performance.now()`・`Math.random()` を使わない。単体テストで時刻と入力を渡して確かめるため
- 層の境界は ESLint の import 制限で機械的に止める（前作と同じ仕組み）

## 3. 決まり

### 3.1 同じ入力からは必ず同じ踊りと音にする（N3・N4）

- 記録するのは**キー入力（何刻み目に、どのキーが押された・離された）と楽器の選択だけ**。姿勢は記録しない。共有URLを開いたら、記録から物理を計算し直して再生する
- 物理は**決まった刻み（1/60秒）で進める**。画面の描画回数（`requestAnimationFrame`）に合わせて刻みを変えない
- ブラウザによって結果が変わりうる計算を `core` で使わない。**`Math.hypot`・`Math.sin` などは使わず、平方根は `Math.sqrt(dx * dx + dy * dy)` で書く**（`Math.sqrt` と四則演算は規格で結果が決まっている。`Math.hypot` 等は実装に任されている）
- 乱数は使わない（使うなら、種を記録に含めた自作の乱数にする）

### 3.2 時刻の基準は音の時計

- 拍は `AudioContext.currentTime` を基準に、自分で先読みして予約する（試作の方式）。**Tone.js の Transport は使わない**（前作で、1つしかない Transport を前の画面の後始末が止める不具合が出た）
- 物理の刻みも音の時計から数える。音の時計が何秒進んだかで、物理を何刻み進めるかを決める

### 3.3 画面が隠れたら一時停止する（N5）

- `visibilitychange` で画面が隠れたら、音を止め（`AudioContext.suspend()`）、物理も止める。戻ったら続きから
- これで、隠れている間に描画やタイマーが間引かれて記録が欠けることがなくなる

### 3.4 音の読み込み

- 楽器の音は数MBになる。**トップページを表示している間に読み込みを始め**、踊る画面に入る前に終わらせる。終わるまでは「準備中」と出す
- ファイルは同じサイト（GitHub Pages）から配信する。外のサイトから直接読まない（相手の都合で消える・遅い。聞き比べでは見本の音を外から読み、初回に10秒ほどかかった）
- 形式は MP3（モノラル）、合わせて 1.5MB 以下（→ [音の読み込みと再生機能](../../03_詳細設計/処理設計/音の読み込みと再生機能.md)）

### 3.5 公開

- GitHub Pages はリポジトリ名のパス（`/stick-dance/`）で配信されるので、Vite の `base` をそれに合わせる
- 公開の範囲は要件どおり（I1）。リポジトリは 2026-11-15 に公開にした

## 4. 楽器の音（サンプル）の条件

**公開・商用利用ができ、改変・再配布が許されている素材だけを使う。** 1ファイルずつ出所と権利を [素材/音の記録](../../素材/音の記録.md) に残す（N7）。

2026-11-15 に一次情報で確かめた候補:

| 素材 | 権利 | 中身 | 判断 |
|---|---|---|---|
| Salamander Grand Piano（Alexander Holm） | CC BY 3.0（README に明記） | グランドピアノ | **使える。** 作者名とライセンスの表記が要る |
| VSCO 2 Community Edition（Versilian Studios） | CC0 1.0（リポジトリの表示。LICENSE ファイル本文は使う前に確かめる） | 鍵盤・弦・金管・木管・打楽器（マリンバ・グロッケン・木琴・ティンパニ・大太鼓・スネア・カウベル等） | **使える。** 表記は不要だが、感謝として載せる |
| tonejs-instruments（nbrosowsky） | サンプルは CC BY 3.0 と書かれているが、出所の一部（Karoryfer・アイオワ大学・Freesound）の条件を確かめられていない | 各種楽器 | **出所が VSCO 2 のものだけ使える**（元の VSCO 2 から取るほうが確実）。それ以外は条件を確かめるまで使わない |
| Tone.js の見本のドラム（`tonejs.github.io/audio/drum-samples/`） | **ライセンスの記載なし** | 生ドラム（聞き比べの D で使った） | **使わない。** 聞き比べ専用にとどめる |

### 4.2 決めたこと（4.1 以降）

- 人ごとの楽器の割り当ては [音の設計方針](音の設計方針.md) 3章
- ベースの高さ: Black And Blue Basses はファイル名の音名がそのまま音の高さ（定義ファイルの `pitch_keycenter` で確認）。段の音の2オクターブ下で鳴らす（[音の並び機能](../../03_詳細設計/処理設計/音の並び機能.md)）
- 取り込む音の数と形式は [音の読み込みと再生機能](../../03_詳細設計/処理設計/音の読み込みと再生機能.md) 設計判断 No.1・No.2
