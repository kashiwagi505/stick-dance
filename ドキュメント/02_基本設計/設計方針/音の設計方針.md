# 音の設計方針

棒人間ダンシングの曲の雰囲気、伴奏、5人分の楽器の割り当てを定める。決定の経緯は [判断ログ](../../01_要件定義/判断ログ.md) D22。
素材の権利は [素材/音の記録](../../素材/音の記録.md)、使う技術は [技術選定の設計方針](技術選定の設計方針.md)。

聞き比べに使ったページ: `prototype/instrument-compare.html`（このページの選び方がそのまま下の表になっている）。

## 1. 曲の雰囲気

| 項目 | 決めたこと |
|---|---|
| 雰囲気 | **POP（ダンスポップ）** |
| テンポ | **124 BPM**（8分音符1つ ≈ 0.24秒） |
| ループ | 4小節（D5）。124 BPM では**約7.7秒**。長さが足りないと感じたら8小節を検討する（→ 4章） |
| コード進行 | Am → F → C → G（1小節ずつ） |
| 音階 | A マイナーペンタトニック（ラ・ド・レ・ミ・ソ）。頭の高さを11段に丸める（D4） |

## 2. 伴奏（ずっと鳴っている）

| 部分 | 音 | 叩き方（1小節 = 8分音符8つ） |
|---|---|---|
| キック | 生ドラム・近め（Virtuosity Drums `Samples/mid/`） | **毎拍**（1・2・3・4拍目。4つ打ち） |
| スネア | 同上 | 2・4拍目 |
| ハイハット | 同上 | 表拍は閉じたハイハット、**裏拍は半開きのハイハット** |
| シンバル | 同上 | ループの頭 |

試作にあった「伴奏のベース」は、2人目（ベース）と役がかぶるので、製品では2人目に任せる方向で基本設計で決める。

## 3. 5人分の楽器

頭の高さ（11段）から音を決める仕組みは全員同じ（D4）。楽器ごとに、その段をどう鳴らすかが違う。踊っている最中からこの音で鳴る（D7）。

| 人 | 役 | 楽器 | 音の出どころ | 頭の高さの使い方 |
|---|---|---|---|---|
| 1人目 | 旋律 | **シンセのリード** | 合成（Tone.js。のこぎり波を3本重ねて広げる＋コーラス） | 段がそのまま音の高さ |
| 2人目 | ベース | **エレキベース（1オクターブ下）** | 録音（Black And Blue Basses の指弾き `darkblack/reg`、CC0） | 段の音を2オクターブ下で鳴らす。POP の型では1拍の中でオクターブを行き来する |
| 3人目 | 和音 | **ひずんだギター風** | 合成（のこぎり波＋ひずみ） | 段の音を根音にした**パワーコード**（根音・5度・オクターブ） |
| 4人目 | 高い旋律 | **シンセのプラック** | 合成（はじくような矩形波＋ディレイ） | 段の音の1オクターブ上 |
| 5人目 | 打楽器 | **手拍子とタンバリン** | 手拍子は合成、タンバリン・トライアングルは録音（Virtuosity Drums の打楽器、CC0） | 段で種類が変わる: 低い（0〜2）→ 手拍子、3〜5 → タンバリン、6〜8 → 軽い手拍子、高い（9〜10）→ トライアングル |

頭の左右の位置は、音色や音の数には使わず、**音の聞こえる左右（パン）だけ**に使う（D25）。全員同じで、楽器の音は変えない。舞台の中央なら真ん中から、端へ寄るほど端から聞こえる。パンの効き方（端でどこまで振るか）は 4章の音量の釣り合いと一緒に耳で決める。

楽器の色（棒人間の色）は試作のとおり、旋律＝黄・ベース＝水色・和音＝桃・高い旋律＝緑・打楽器＝紫を出発点にする。

## 4. まだ決まっていないこと

- **ループの長さ**: 124 BPM の4小節は約7.7秒。本人は以前「5秒は短い」と言い、4小節（100 BPM で約10秒）に決めた。7.7秒で足りるか、8小節（約15.5秒）にするかを試作で確かめる
- **ギターの録音**: 今はギター風の合成音。本物のギターの録音（権利の明らかなもの）に替えるかは、素材が見つかってから聞き比べる
- **1人目と4人目が同じシンセ系**: 旋律（リード）と高い旋律（プラック）がどちらも合成で、重ねたときに聞き分けられるか（AC2）を、5人そろった状態で確かめる
- **パンの効き方**: 舞台の端で左右へどこまで振るか（D25）。5人重ねたときに聞き分けやすく、片耳に寄りすぎない値を探す
- **音量の釣り合い**: 聞き比べページの値は仮。5人重ねて、誰の音も埋もれないように調整する
- **伴奏のベースを残すか**（2章）
