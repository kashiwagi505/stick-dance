## 1. ケースの前提

| 前提の記号 | 前提の作り方 |
|---|---|
| P1 | `/`（`#` なし）を新しいページで開く |
| P2 | P1 のうち、楽器の音のファイル（`/sounds/` 以下）への通信を spec 側で失敗させてから開く |

- 時間は固定しない（テスト方針4-3）。読み込みが終わるのは「はじめる」が押せるようになるのを待って確かめる。

## 2. 観点表

| ケースID | 観点 | 確認内容 | 前提 | 自動化 |
|---|---|---|---|---|
| SCR01-01 | 初期表示 | タイトル「棒人間ダンシング」（見出し1）とリード文が出る。開いた直後は「準備中」で押せず、「楽器の音を読み込んでいます」が出る。読み込みが終わると「はじめる」が押せるようになり、案内が消える。「音が出ます」と「クレジット」が出る | P1 | 済 |
| SCR01-02 | 異常系 | 楽器の音を読み込めないと、「再読み込みする」が押せる状態で出て、「楽器の音を読み込めませんでした。通信できる状態にして、再読み込みしてください。」が出る。「音が出ます」は出ない | P2 | 済 |
| SCR01-03 | エラー後の再操作 | 読み込みに失敗したあと、通信できる状態にして「再読み込みする」を押すと、読み込み直して「はじめる」が押せるようになる | P2 | 済 |
| SCR01-04 | 入力チェック | トップで踊りのキー（W・↑・1・Space）を押しても、画面は切り替わらず何も起きない | P1 | 済 |
| SCR01-05 | 画面遷移 | 「はじめる」を押すと踊る画面（SCR02）に切り替わり、分身 0 / 5、楽器は 1 旋律が選ばれ、最初の1周のヒント「キーで手を引っぱる」と「1人目を踊っています」の案内が出る | P1 | 済 |
| SCR01-06 | 画面遷移 | 「クレジット」を押すとクレジットの窓（DLG01）が開き、見出し「クレジット」が出る | P1 | 済 |
| SCR01-07 | 外部通信 | 開いてから読み込みが終わるまで、ページと同じサイトの外への通信が起きない（楽器の音は同じサイトの `/sounds/` から読む） | P1 | 済 |
| SCR01-08 | 表示幅（PCのChrome） | Desktop Chrome の表示幅で横スクロールが出ない | P1 | 済 |

- 音の聞こえ方は確かめない（テスト方針2-1）。
