# 繰り返している指示の棚卸し

`prompt-log` フックが拾えるのは**字面の近い繰り返しだけ**。同じ趣旨で言い回しが違う繰り返しは機械では拾えないため、ここでAIが読んでまとめる。あわせて失効した暫定ルールを検出する。

正本: [コマンド・スキル利用ガイド](../../ドキュメント/基準書/コマンド・スキル利用ガイド.md)、[暫定ルール](../../ドキュメント/基準書/暫定ルール.md)

## 対象と対象外

- **対象**: `.claude/tmp/prompt-log.jsonl` に記録された人間のプロンプト。
- **対象外**: スラッシュコマンドの呼び出し（すでに仕組み化済みのためフックが記録しない）。

## 手順

### 1. 記録を読む

```powershell
if (Test-Path .claude/tmp/prompt-log.jsonl) { (Get-Content .claude/tmp/prompt-log.jsonl | Measure-Object -Line).Lines } else { "記録なし" }
```

期間は `$ARGUMENTS`（省略時は直近7日）。件数が多い場合は `Explore` へ委譲して読ませ、生ログをメイン会話へ持ち込まない（[AGENTS.md](../../AGENTS.md)）。

### 2. 趣旨でまとめる

**字面ではなく意味でまとめる。** 言い方が違っても同じことを求めているものは1グループにする。

各グループについて次を出す。

- 趣旨（1行）
- 回数、初出日、最終出現日
- 代表的な原文2件（各40文字以内に切る）
- **すでにルールとして書かれているか**（`AGENTS.md`・`ドキュメント/基準書/`・`ドキュメント/AGENTS.md`・`.agents/` を検索して確認する）

### 3. 仕分ける

| 状態 | 意味 | 次の手 |
|---|---|---|
| 3回以上・未記載 | 仕組みに上げる候補 | `/rule-new` を提案する |
| 3回以上・**記載済み** | **書いてあるのに守られていない**。最も重い | 検査方法が無いことが原因。`/rule-new` の問2から作り直す |
| 2回以下 | まだ判断できない | 何もしない |
| リトライ・進捗確認 | 仕組みの対象外 | 何もしない |

2行目を見落とさない。委譲のルールは `AGENTS.md:14` に書かれているにもかかわらず、2026-08-14から09-03まで8回言われ続けた。**記載済みで繰り返されているものは、書き足しても直らない。**

### 4. 暫定ルールの失効を確認する

[暫定ルール](../../ドキュメント/基準書/暫定ルール.md) の各行について、撤回条件が満たされているかを実際に確認する（ファイルの存在、期限の日付、Issueの状態）。

満たされている行は、撤回条件の「撤回時にやること」を実行し、その行を「撤回済み」へ移す。

### 5. 報告する

- グループ一覧（回数の多い順、上位10件程度）
- 仕分け結果と、`/rule-new` を提案する項目
- 撤回した暫定ルール、または撤回すべきだができなかったもの

## 終わり方

一覧を提示して終了する。**ルールの追加・撤回は人の判断を得てから行う。**このコマンド自身がルールを書き換えることはしない（暫定ルールの撤回だけは、条件を満たしていることを示したうえで承認を得て行う）。
